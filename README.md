# GroceryApp_Android-Studio


---

### ✨ About the App

The **GroceryMart App** is a digital platform designed to streamline the grocery shopping experience by providing a user-friendly platform for browsing and purchasing items.The app features a splash screen that transitions users into the main interface, which displays various grocery categories, promotional offers, and recently viewed products.With its clean and intuitive interface, the "Grocery Shop App" aims to make grocery shopping convenient and efficient, enhancing the overall user experience.

---

### 🚀 Key Features

* **Splash Screen** 🖼️: The app launches with a splash screen to greet users and ensure a seamless transition into the main app interface.

* **Home Screen** 🏠: This is the main activity where you can see different grocery item categories, deals, and products you've recently visited.

* **Product Details** 🔎: Customers can see comprehensive details, such as pictures, descriptions, costs, and availability, regarding a chosen selection of products.

* **Category Browsing** 🛒: The app makes it simple to locate product categories by allowing users to browse goods by category.

* **Search Functionality** 🔍: The app also includes a search function to quickly find specific products.

* **Intuitive UI** 🎨: The app uses preloaded fonts and defined styles to ensure a consistent and visually appealing design.

---

### 🛠️ Getting Started

To get a copy of the project up and running on your local machine, follow these simple steps.

#### Installation

1.  Clone the repository:

    ```bash
    git clone https://github.com/SindhujaShaga/GroceryApp_Android-Studio.git
    ```

2.  Open the project in Android Studio.

3.  Use a **Pixel 7a Emulator with API 32** to run the application.
