### 📖 About the App

The **GroceryMart App** is a digital platform designed to streamline the grocery shopping experience directly from your mobile device. With a clean, intuitive, and visually appealing interface, it allows users to effortlessly browse, search, and purchase grocery items. ### 📖 About the App

The **GroceryMart App** is a digital platform designed to streamline the grocery shopping experience directly from your mobile device. Built with a clean, intuitive, and visually appealing interface, it allows users to effortlessly browse, search, and purchase grocery items. The app aims to make shopping more efficient and convenient, from the initial splash screen to the final purchase.

---

### ✨ Key Features

* **Splash Screen (`SplashActivity`):** The app launches with a `SplashActivity` that displays the app's logo and name, ensuring a seamless and branded entry point. This activity handles initial background tasks, such as loading resources and setting up configurations, before transitioning to the main interface.

* **Home Screen (`MainActivity`):** This is the core of the application's user interface. It is a single activity that dynamically displays various grocery categories, promotional offers, and a horizontally scrollable list of recently viewed products.

* **Product Details:** Users can access a `ProductDetails` screen to view comprehensive information about selected products. This includes high-quality images, detailed descriptions, prices, and availability. The page automatically updates with new item details when the user navigates to a different product.

* **Efficient Navigation:** The app provides seamless navigation between screens, allowing users to browse categories and view product details with intuitive back navigation. The "Select Category" section enables users to view detailed food items, with the ability to return to the main screen by clicking the back icon.

* **Adaptive UI:** The application uses preloaded fonts and defined styles to ensure a consistent and visually cohesive design across all screens.

---

### 🛠️ Challenges and Solutions

Developing this application from scratch presented several interesting challenges, particularly in creating a dynamic and responsive user interface.

* **Implementing a Custom Scroll View:** One of the main challenges was to implement a horizontally scrollable list for sections like "Top Discounted Items" and "Recently Viewed Items." This required careful integration of `ScrollView` within the main activity's layout to ensure a smooth user experience without conflicting with vertical scrolling.

* **Managing Dynamic Content:** The product details page was designed to be dynamic, automatically updating its content based on the user's selection from the recently viewed items. This was achieved by passing data between activities and ensuring the UI components were correctly re-rendered to display the new information, preventing the need for a separate activity for each item.
